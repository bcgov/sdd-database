# Steps to add a new field

1. Add to schema.prisma, migrate
2. Seed the data
3. Make sure you have appropriate assertions while seeding if needed

4. Add DB access functions
5. update src/types.ts (Entity, ...) if needed
5. Add action file
6. Add hook file 

8. Showcase in the UI
8. Make sure you do validate if required

10. Allow searching for this field through the search box
